# 2. Problem definition and initial conditions

Use the one-dimensional drift-diffusion equation:

\[
\frac{\partial p}{\partial t}
=
a\frac{\partial p}{\partial x}
+
D\frac{\partial^2p}{\partial x^2}
\]

where:
- \(p(x,t)\) is the probability density.
- \(a\) is the drift coefficient.
- \(D\) is the diffusion coefficient.

Use a Gaussian initial distribution:

\[
p(x,0)=
\frac{1}{\sqrt{2\pi\sigma_0^2}}
\exp\left[
-\frac{(x-x_0)^2}{2\sigma_0^2}
\right]
\]

The original paper assumes periodic spatial boundary conditions.

Therefore, use a wrapped Gaussian or a sufficiently wide periodic domain with negligible boundary effects. Clearly state which approach is used.

Provide the analytical solution for validation.

For the infinite-domain Gaussian solution:

\[
\mu_t=x_0-at
\]

\[
\sigma_t^2=\sigma_0^2+2Dt
\]

The solution is:

\[
p(x,t)=
\frac{1}{\sqrt{2\pi\sigma_t^2}}
\exp\left[
-\frac{(x-\mu_t)^2}{2\sigma_t^2}
\right]
\]

If using a periodic domain, implement the corresponding wrapped version for accurate validation.

Define all parameters in one cell:

- Domain boundaries and length.
- Number of spatial points \(N\).
- Spatial step \(\Delta x\).
- Time step \(\Delta t\).
- Total simulation time \(T\).
- Number of time steps \(n_t\).
- Drift coefficient \(a\).
- Diffusion coefficient \(D\).
- Initial centre \(x_0\).
- Initial standard deviation \(\sigma_0\).

Choose parameters satisfying the explicit finite-difference stability condition.

If interpreting the finite-difference coefficients as random-walk probabilities, ensure they are nonnegative.

Explain the sign convention: with the PDE written above, the Gaussian centre moves towards decreasing \(x\) when \(a>0\).

# 3. Method 1 — Classical direct time evolution

Discretise the PDE using forward-time, centred-space finite differences.

Use:

\[
p_i^{k+1}
=
c_0p_i^k+c_+p_{i+1}^k+c_-p_{i-1}^k
\]

where:

\[
c_0=1-\frac{2D\Delta t}{\Delta x^2}
\]

\[
c_+=
\frac{a\Delta t}{2\Delta x}
+
\frac{D\Delta t}{\Delta x^2}
\]

\[
c_-=
-\frac{a\Delta t}{2\Delta x}
+
\frac{D\Delta t}{\Delta x^2}
\]

Use periodic indexing.

Construct the spatial evolution matrix \(L\):

\[
\mathbf p^{k+1}=L\mathbf p^k
\]

Implement direct time evolution by repeatedly applying this update.

Show:
- Initial Gaussian.
- Several intermediate time steps.
- Final distribution.
- Comparison with the analytical solution.

Explain:
- What the spatial index \(i\) represents.
- What the time index \(k\) represents.
- How drift and diffusion affect the distribution.
- Why periodic indexing is required.

Give the computational complexity:

\[
O(n_tN)
\]

Do NOT implement:
- The full block linear system.
- Conjugate gradient.
- Condition-number calculations.
- Other classical algorithms.

# 4. Method 2 — Classical FFT diagonalisation

Explain that constant coefficients and periodic boundaries make the evolution matrix circulant.

A circulant matrix can be diagonalised by the discrete Fourier transform:

\[
L=F^\dagger\Lambda F
\]

Therefore:

\[
\boxed{
\mathbf p(T)=F^\dagger\Lambda^{n_t}F\mathbf p(0)
}
\]

Calculate the eigenvalues of the finite-difference evolution matrix.

For the chosen discretisation:

\[
\lambda_j=
1-
\frac{4D\Delta t}{\Delta x^2}
\sin^2\left(\frac{\pi j}{N}\right)
+
i\frac{a\Delta t}{\Delta x}
\sin\left(\frac{2\pi j}{N}\right)
\]

Use NumPy FFT and inverse FFT to implement the evolution.

The implementation must use the exact same discrete eigenvalues as Method 1.

IMPORTANT:
- Do not replace the finite-difference eigenvalues with the continuous PDE Fourier propagator.
- Do not use a different discretisation for this method.
- The direct evolution and FFT methods must solve exactly the same discrete problem.

Show:
1. Initial spatial distribution.
2. Fourier coefficients.
3. Evolved Fourier coefficients.
4. Reconstructed final distribution.

Compare the final FFT result with direct time evolution.

Print their numerical difference or relative error.

Explain the computational complexity:

\[
O(N\log N)
\]

Clarify that this counts the FFT-based evolution, excluding any separately considered setup costs.

Do not reproduce the full mathematical proof of circulant diagonalisation. Explain the intuition and retain the eigenvalue formula.

## 5.3 Non-unitary diagonal evolution

The required spectral evolution is:

\[
H=\operatorname{diag}
\left(
\lambda_0^{n_t},
\lambda_1^{n_t},
\ldots,
\lambda_{N-1}^{n_t}
\right)
\]

This operator is generally non-unitary.

A quantum circuit cannot directly apply an arbitrary non-unitary matrix as an ordinary gate.

Implement the operation using an ancilla-assisted unitary dilation.

Define:

\[
\alpha=\max_j|\lambda_j^{n_t}|
\]

and:

\[
K=\frac{H}{\alpha}
\]

Then \(K\) is a contraction.

Construct a unitary \(U\) acting on the spatial register and ancilla such that:

\[
\boxed{
\langle0|_{\mathrm{anc}}U|0\rangle_{\mathrm{anc}}=K
}
\]

One valid construction is the unitary dilation:

\[
U=
\begin{pmatrix}
K & \sqrt{I-KK^\dagger}\\
\sqrt{I-K^\dagger K} & -K^\dagger
\end{pmatrix}
\]

with the block ordering chosen consistently with the ancilla basis.

Verify numerically that the ancilla-zero block of the constructed unitary equals \(K\).

Do not invent controlled rotations or phase gates and assume they implement the complex eigenvalues correctly.

If the full unitary is too large or difficult to construct, use a correct small-system construction for \(N=8\), and explain its limitations.

## 5.4 Inverse QFT and postselection

After the diagonal operation, apply the inverse QFT:

\[
F^\dagger
\]

The ancilla-zero branch contains the evolved state, up to the scaling factor \(\alpha\).

Measure the ancilla and postselect on:

\[
|0\rangle_{\mathrm{anc}}
\]

Explain that postselection extracts the desired non-unitary evolution branch.

Calculate the theoretical postselection probability:

\[
P(0)=
\left\|
K|\psi_F\rangle
\right\|_2^2
\]

Compare this with the probability obtained from the Qiskit simulation.

Mention amplitude amplification as a possible way to improve postselection success, but do not implement a full amplitude-amplification algorithm unless it is straightforward and mathematically correct.
